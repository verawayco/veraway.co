Services

Three ways to work together

Start where the project is: stuck, starting, or underway and short-handed.

01 · 2 weeks · Fixed fee

Project Reset

For a project that's mid-stream and slipping. A fast diagnosis and a clear path forward.

  • Stakeholder and vendor interviews
  • Scope, schedule, and status assessment
  • Written recovery plan with top risks and decisions
02 · 3–4 weeks · Fixed fee

Project Launch

For a project that's approved but not yet structured. Everything it needs to start right, then handed to your team.

  • Charter: goals, scope, budget, success measures
  • Schedule with milestones and dependencies
  • Roles (RACI), risk register, communication plan
  • Tracking set up in the tools you already use
  • Facilitated kickoff and a handoff playbook
03 · 3–6 months · Monthly retainer

Fractional PM

Project Launch, plus a PM who stays on to run it week to week, part-time but fully engaged.

  • Weekly status meetings and leadership updates
  • Vendor and contractor coordination
  • Risk, issue, and change control
  • Monthly steering review and close-out report
